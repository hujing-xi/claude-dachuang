📋 训练计划

科学系统的训练方案，从入门新手到专业球员，找到最适合你的训练节奏。

新手入门 4周
🌱 篮球零基础入门计划
⏱ 每次 60 分钟 📅 每周 3 次 🎯 适合完全零基础
第1周
基础运球（原地拍球、行进间运球）+ 投篮手型练习（无跳投，只练出手）
第2周
体前变向运球 + 定点跳投（罚球线）+ 滑步防守基础动作
第3周
三步上篮（左右手）+ 胸前传球对练 + 折返跑体能训练
第4周
1对1基础对抗 + 综合复习前三周内容 + 半场3对3比赛实践
进阶提升 8周
⚡ 进阶综合能力提升计划
⏱ 每次 90 分钟 📅 每周 4 次 🎯 有基础者
第1-2周
高阶运球组合（胯下+背后+转身）+ 急停跳投 + 1对1防守对抗
第3-4周
后撤步训练 + 挡拆配合跑位 + 二打一快攻模拟
第5-6周
三分球专项（弧顶、45°、底角）+ 无球跑位 + 区域联防破解
第7-8周
综合技术融合训练 + 5对5全场对抗 + 针对弱项强化
高水平 12周
🏆 赛季前准备训练计划
⏱ 每次 120 分钟 📅 每周 5 次 🎯 竞技水平球员
第1-3周
体能基础强化（力量+有氧），重点提升腿部爆发力与核心稳定性
第4-6周
技术精细化（投篮机制、传球视野），全场对抗模拟比赛
第7-9周
战术体系灌输（本队进攻战术、防守轮转），专项位置练习
第10-12周
高强度模拟比赛 + 心理状态调节 + 赛前减量，保证体能巅峰
位置专项 6周
🎮 控球后卫专项训练
⏱ 每次 90 分钟 📅 每周 4 次 🎯 PG 位置球员
运球
全套高阶变向运球（胯下/背后/转身组合）+ 限速区低头运球训练
传球
无看传球 + 突破分球 + 挡拆后的传球选择训练
得分
挡拆后弹跳投篮 + 中远距离急停跳投 + 欧洲步上篮
战术
组织进攻节奏控制 + 全队快攻发动 + 末节比赛管理能力
位置专项 6周
🗼 中锋专项训练
⏱ 每次 90 分钟 📅 每周 4 次 🎯 C / PF 位置球员
低位
低位单打技术（背身勾手、转身强攻）+ 脚步步法梦幻步练习
篮板
Box Out 卡位技术 + 进攻篮板二次进攻 + 高点抢球爆发力
防守
封盖时机判断 + 协防补防站位 + 拆挡还原防守移动
策应
高位掩护技术 + 挡拆后的滚动与弹出选择 + 短传配合
新手入门 2周
💪 投篮专项提升计划
⏱ 每次 45 分钟 📅 每天 🎯 改善投篮命中率
每日
200次定点投篮（5个点各40次：底角、45°、弧顶），重心感受慢速练习
隔天
接球即投练习（有人传球）+ 运球急停跳投 + 三分线外定点尝试
记录
每次训练记录各点命中率，对比进步曲线，找到自己的强弱点
📅

通用周训练模板（进阶级别参考）

周一
投篮 + 运球技术日
热身 10min → 运球技术组合 20min → 定点跳投 200次 → 拉伸 10min
周二
体能 + 防守日
热身 10min → 折返跑 4组 → 滑步防守训练 25min → 核心力量 15min
周三
主动恢复日
瑜伽或轻度拉伸 30min，低强度原地运球，关注身体恢复状态
周四
技术对抗日
热身 10min → 1对1对抗训练 30min → 挡拆配合演练 20min → 拉伸
周五
投篮专项日
热身 10min → 三分专项训练 30min → 中距离急停跳投 → 罚球 50次
周六
全场比赛日
正式5对5全场比赛，专注将本周练习的技术运用到实战中，赛后复盘
周日
完全休息日
充分休息，保证睡眠质量，为下周训练储备体力
⚠️ 训练注意事项

1. 循序渐进：不要急于求成，技术动作的质量比完成数量更重要。
2. 充分热身：每次训练前必须热身，特别是踝关节和膝关节的活动。
3. 记录进步：建议记录训练日志，追踪命中率、完成组数等数据，客观评估进步。
4. 保证恢复：肌肉在休息中生长，不要连续高强度训练超过3天。
